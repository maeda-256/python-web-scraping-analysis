# python-web-scraping-analysis
### 概要
日本語のWebサイトから形態素解析を用いて統計・分析を行うPythonのスクリプト集です。大学でのプログラミングの講義で作成したものを一部改変して作成しています。
- 「in」というフォルダにデータが与えられており、「out」というフォルダに出力されることを想定しています。
- ＊入力データ、出力データは大学提供のため、非公開としております

### 主な機能
- BeautifulSoupを用いたニュース記事の自動抽出
- 弊学学長式辞のテキストマイニング（頻出単語の可視化）
- ホットペッパーAPIデータ地域別予算比較

### 使用技術
- 言語:Python3.11+
- ライブラリ:Pandas, BeautifulSoup4, Janome, requests
